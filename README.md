# Handwritten SVG Text

Handwritten text drawn with SVG stroke animation.

![Screenshot](github-contents/screenshot.png)

**Live demo:** [https://rogue-dev-studio.github.io/handwritten-svg-text-animation/](https://rogue-dev-studio.github.io/handwritten-svg-text-animation/)

## Highlights
- SVG path stroke
- Handwriting feel

## Run
Open `index.html` locally (Live Server on port **5500**), or use the live demo above.

```bash
git clone https://github.com/rogue-dev-studio/handwritten-svg-text-animation.git
```
